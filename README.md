# TECHNO STORE

Учебный проект по теме «Блочная вёрстка с применением CSS Grid».

## Структура проекта

- `index.html` — разметка страницы.
- `css/style.css` — оформление и CSS Grid.
- `img/` — папка для изображений (в этом варианте товары нарисованы средствами CSS).

## Как открыть

Откройте файл `index.html` в браузере.

## Что использовано

- `grid-template-areas` — схема расположения header, sidebar, main и footer.
- `grid-area` — привязка блоков к областям.
- `repeat(auto-fit, minmax(220px, 1fr))` — адаптивная сетка товаров.
- `grid-column: span 2` — увеличенная первая карточка.
- `gap` — расстояние между карточками.
- `@media` — перестройка страницы для мобильных экранов.

JavaScript не используется.
